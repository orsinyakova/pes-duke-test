# Pes Duke — тестовый стенд

Отдельная версия первого экрана для проверки дизайна, скорости загрузки и фонового видео.

HTML, CSS и JavaScript — в `index.html`, изображения, шрифты и видео — в `assets/`. В мобильной версии загружается облегчённое видео. При включённом уменьшении движения остаётся статичный постер.
