# Pes Duke — тестовый стенд

Отдельная версия первого экрана для проверки дизайна, скорости загрузки и фонового видео.

HTML, CSS и JavaScript — в `index.html`, изображения, шрифты и видео — в `assets/`. В мобильной версии загружается облегчённое видео. При включённом уменьшении движения остаётся статичный постер.

## Команда

Блок `#team` содержит четырёх действующих специалистов из Yclients. На широком экране карточки стоят в один ряд, на планшете и телефоне доступны горизонтальное листание и стрелки. Фотография Елены оптимизирована в WebP; инициалы остальных мастеров согласованы как временное оформление. Источники: [docs/team-sources.md](docs/team-sources.md).

Появление элементов запускается через IntersectionObserver и GSAP; при уменьшении движения отключено. Видео первого экрана приостанавливается вне области видимости.
